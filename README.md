# AURUM Elite Fitness

Welcome to the AURUM Elite Fitness website repository. This is a premium, single-page luxury gym website built with HTML, CSS, and Vanilla JavaScript.

## Features

- **Premium Design:** Dark mode by default with elegant gold accents, tailored for a luxury aesthetic.
- **Responsive Layout:** fully optimized for both mobile and desktop screens.
- **Light/Dark Mode:** Built-in theme toggler that gracefully switches the site between dark and light themes.
- **RTL Support:** Right-To-Left layout support for localized content.
- **Dynamic Routing:** Single-page application logic using Vanilla JS to switch between views (Home, About, Services, Contact, Auth, and Dashboards).
- **Interactive UI:** Smooth animations, glassmorphism effects, and custom SVG icons.
- **Member Portals:** Includes mockups for both Client and Admin dashboards.

## Getting Started

Since this is a static website, no build process is required.

1. Clone the repository.
2. Open `AURUM_Gym_Website.html` directly in your web browser.

## Deployment

This project is configured for easy deployment on [Vercel](https://vercel.com/).

The included `vercel.json` automatically rewrites the root URL (`/`) to serve `AURUM_Gym_Website.html`, so the site loads correctly when deployed.

Simply import the repository into Vercel, and it will deploy instantly.
